MOVIEBOX TAŞINABİLİR MACOS PAKETİ
================================

Bu paket Apple Silicon işlemcili (M1/M2/M3/M4/M5) MacBook modelleri içindir.

Kurulum:

1. ZIP dosyasını açın.
2. Kur-MovieBox.command dosyasına çift tıklayın.
3. macOS dosyayı engellerse sağ tıklayıp "Aç" seçeneğini kullanın.
4. Kurulum tamamlanınca yeni bir Terminal açın.
5. moviebox komutunu çalıştırın.

Kurucu şunları otomatik yapar:

- Gerekirse Homebrew kurar.
- Chafa ve mpv bağımlılıklarını kurar.
- MovieBox uygulamasını ~/.local/bin altına kurar.
- SubDL ve OpenSubtitles API anahtarlarını ~/.config/moviebox-tui altına kurar.
- moviebox ve eski moviebox-tui komut adlarını hazırlar.

GÜVENLİK
--------

Bu paket kişisel API anahtarları içerir. ZIP parolasını ve ZIP dosyasını
başkalarıyla paylaşmayın. Paketi yalnızca güvendiğiniz Mac bilgisayarlara
kopyalayın.
